# Dj Nass Audiovisuel

Site vitrine responsive pour Dj Nass Audiovisuel, studio audio et services de production vidéo basés à Zinder, Niger.

## Contenu
- `index.html` : page principale du site.
- `assets/dj-nass-portrait-studio.jpeg` : portrait en studio fourni par Dj Nass.
- `assets/dj-nass-portrait-outdoor.jpeg` : portrait extérieur fourni par Dj Nass.
- `assets/dj-nass-logo.png` : logo visuel du studio.

## Aperçu local
Ouvrir `index.html` dans un navigateur récent. Garder le dossier `assets/` à côté du fichier HTML.

## Déploiement sur Vercel
1. Importer ce dossier dans un dépôt GitHub.
2. Dans Vercel, importer le dépôt.
3. Pour ce site HTML statique, sélectionner **Other** si Vercel demande un framework et laisser la commande de build vide.
4. Déployer, puis vérifier que le domaine est attaché au déploiement Production.

## Référencement
Le titre et la description SEO sont présents dans le HTML. Après le déploiement, ajouter le domaine réel dans Google Search Console et demander l'indexation de la page d'accueil.
